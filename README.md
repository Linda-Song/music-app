# Music App (Spotify Clone)

A web-based music application inspired by Spotify, built with React, TypeScript, and React Router.

## Tech Stack
* **Frontend:** React, TypeScript, React Router DOM
* **Styling:** CSS
* **Build Tool:** Create React App (CRA)

## Key Features
* **Home Page:** Explore curated music and playlists.
* **Search Page:** Browse music genres and categories.
* **Search Results:** Real-time keyword-based search (`/search/:keyword`).
* **Playlist Details:** View individual playlist tracks and information (`/playlist/:id`).
